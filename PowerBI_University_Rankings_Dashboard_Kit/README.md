# Power BI — University Rankings Insights Dashboard

This is a **mini portfolio project** showing end-to-end analytics workflow:
**clean dataset → measures (DAX) → interactive dashboard design**.

## What’s included
- `data/powerbi_university_rankings_dataset.csv` — cleaned/enriched dataset
- `powerbi/BUILD_GUIDE.md` — build the dashboard in ~20–30 minutes
- `powerbi/DAX_MEASURES.md` — measures you can copy/paste
- `analysis/QUICK_INSIGHTS.md` — auto-generated insights for storytelling
- `visuals/` — sample charts you can use in your README

## Dashboard pages (recommended)
1. **Overview:** KPIs + Avg Score by Country + table + slicers
2. **Geography:** Map using latitude/longitude + tooltips
3. **Anomalies & Trends (optional):** scatter + outlier table
